# Qoder F01–F03 案例材料

这些材料对应[会前讨论稿](../qoder-f01-f03.md)。每个案例包含实际提交的任务、观察到的行为和独立验收结果。各案例说明如何使用随附材料，以及复测的依赖条件。

| 案例 | 随附材料 |
| --- | --- |
| [F01 · 桌面导出兼容性](f01/README.md) | 用户任务、冻结验收统计、关键实现差异、普通文件前后输出、生成合成插件的复核脚本 |
| [F02 · 编辑后保存与预览重绘](f02/README.md) | 用户任务、四组页面、Qoder 的测速脚本、实现差异、配对读数、制表符回归输入和复核脚本 |
| [F03 · 桌面笔记本导入](f03/README.md) | 用户任务、13 份原始样例与验收文件、桌面改动、运行时间线、依赖摘要和独立验收结果 |

实际运行使用各自的 Prettier 工作区。自行复核需要准备说明中列出的工作区或依赖。公开材料中的证据记录已移除本机绝对路径和会话标识。
