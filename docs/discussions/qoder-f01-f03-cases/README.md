| 案例 | 实测发现 | 证据 |
| --- | --- | --- |
| [F01 · 兼容性修复](f01/README.md) | 原有验收通过，普通文件却静默换了格式化插件 | [验收、补丁与前后输出](f01/evidence.md) |
| [F02 · 保存性能](f02/README.md) | 保存测速使用重复预览负载，另外复现了缩进回归 | [测速脚本、配对读数与样例](f02/evidence.md) |
