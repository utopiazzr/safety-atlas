# 非攻击性智能体评测产品

完整的产品脉络、技术路线和已测案例统计见 [产品脉络与验证总结](./PRODUCT_OVERVIEW.md)。

Safety Atlas 提供可安装、可卸载的 Python 智能体安全插件。将选定工具包在 `SafetyPlugin.wrap_tool` 中，正常调用后自动产生评测、监控与修复建议。网站提供安装引导、技术路线、可核对案例、浏览器本地评测与统一结果展示。

最短使用路径见 [插件安装说明](../product/README.md#快速开始)，只需安装 wheel 并运行 `scisec-agent quickstart --open`。接入自己的工具只需 import、创建插件、包住工具三步。初次运行只验证实际本地普通函数调用；业务权限、完成报告和语义评分按需配置。

## 用户路径

1. 安装 Python 插件，挂接选定工具；LangChain / OpenTelemetry / Casbin 可按需接入。
2. 用正常业务任务生成脱敏事件、行为轨迹或回答依据评测账本。
3. 运行 `scisec-agent run-pipeline manifest.json report.json --html report.html`。
4. 在 Safety Atlas 的“评测产品”页打开 `report.json`。浏览器只在本地解析，不上传文件。
5. 根据修复队列调整权限、报告绑定或工具配置，用同一个正常用例和稳定事件 ID 复测并比较证据。

默认模式不改变原工具权限。`enforce` 需明确业务策略；结果修复队列由用户确认实施。权限未知、空观测、未核实引用、矛盾评审、未完成评分和语义依据分数不足不会显示为无问题。网页本地处理输入，不建立云端评测账户或上传私有轨迹。

## 已验证范围

- 独立 Python wheel 可构建、安装和运行；
- 真实 PyCasbin 与 LangChain 中间件集成测试；
- OpenTelemetry 脱敏工具事件；
- Ragas 0.4.4 兼容的回答依据评测及可恢复 SQLite 账本；
- 外挂存储上的小型合成结果写入/读回，账本与结果分离；
- 统一流水线生成 JSON 与静态 HTML；
- 网站只读加载公开合成示例或用户本地结果。

这些验证不代表真实生产模型、任意挂载容量或所有智能体框架已经通过。活动 SQLite/WAL、身份凭据和原始私有轨迹不得放入公开网站或对象存储挂载。

## 空间维护记录

2026-11-23，两个已终态且无活动进程引用的产品工作区被流式归档到授权外挂存储；归档逐个读回校验后才移除本地副本。约 1.21 GB 逻辑源数据得到可恢复归档。服务器系统盘仍受到本产品目录之外的容量竞争，生产 API 未据此宣称恢复。仓库不保存归档、数据库、私有会话或服务器地址。
