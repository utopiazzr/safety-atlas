# 视觉叙事：人类掌舵的未来观测站

目标不是在普通目录上贴机器人，而是让首页、海报、回放和投稿处于同一个世界：发现异常信号，理解它跨过了什么边界，再连接防御与人的判断。

## 学习来源与设计转译

- [Science Museum：Cosmonauts](https://journal.sciencemuseum.ac.uk/article/the-cosmonauts-challenge/) 与 [展览设计记录](https://journal.sciencemuseum.ac.uk/article/cosmonauts-birth-of-an-exhibition/)：研究苏联航天视觉和展陈中的人、器械与宇宙。本项目提取朱红、黑色、暖纸色、对角构成和大尺度图文关系。
- [NSS：Stanford Torus](https://nss.org/stanford-torus-space-settlement/)：1975 年 NASA/Stanford 空间居住研究，收录 Don Davis、Rick Guidice 的轨道建筑绘画。本项目使用环形结构、行星地平线和人类建造的未来设施。
- [NANZUKA：Hajime Sorayama](https://nanzuka.com/en/artists/hajime-sorayama) 与 [Space Traveler](https://en.shop.nanzuka.com/products/sexy-robot_space-traveler-1-6-scale)：研究镜面机器人的反射、机械分缝和有机轮廓。本站资产为新生成插画，并非原作或授权联名。

以上为设计参考，具体配色、构图和交互映射是项目设计判断。

## 统一语言

案例卡的新插画参考 [Taguchi Art Collection 收藏的《Untitled》(2015)](https://taguchiartcollection.jp/en/artwork/tac330/)。该馆标注的媒材为 acrylic on illustration board。从画面观察，简洁粉色背景、细致轮廓、柔和银蓝反射与暖色边缘让机械主体清晰突出。本项目据此重绘自己的九个安全机制隐喻：减少密集星空和环境细节，以平面几何色底、放大的银铬主体和喷绘过渡强调插画感。没有复制原作的人物、构图或品牌元素。

深绿黑太空、暖银铬、朱红警示与奶油色标题条。以硬边漫画分镜、半调网点和印刷式色块保持平面性；用金属主体与轨道尺度表达幻想。减少小字，标题、类型、图像优先。

案例插画分别暗示信息出界、记忆、工具链、优化、对话、探测、防护关卡、分类视线和扫描。它们是视觉隐喻，不能充当证据。代码动画以真实的场景阶段控制信号运动：跨会话回路、越界线、检查位置，不播放虚构的攻击成功率。

浏览器的动效关闭按钮与系统减少动态效果偏好都有效。卡片点击打开一份档案；核心证据和运行条件放入展开项；投稿只要求一份材料，其他字段可选。
